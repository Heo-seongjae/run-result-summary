# 교량 전단연결재 3차원 위치 찾기 — 연구 소개

**사진 · 헤드 마스크 · 마커 위치를 넣으면, 정답 번호 없이 교량 전단연결재 84개를 하나하나 짝지어 3차원 위치를 찾는다.**
촬영 전에 BIM으로 시점을 고르고, 그 시점에서 찍은 사진으로 카메라 자세를 복구해 3차원 영역을 만든다.

> 부경대학교 토목공학과 허성재 (지도 이준화 교수) · 논문 투고 전

## 1. 문제

- 강거더 위 전단연결재 84개는 **모양이 전부 같고 거의 한 평면**에 있다.
- 여러 사진에서 "이 헤드가 저 사진의 어느 헤드인가"를 맞추기가 어렵다(반복 패턴).
- 그래서 **찍기 전에** BIM으로 "서로 헷갈리지 않는 시점"을 고른다.

## 2. 방법

| 입력 | 하는 일 | 출력 |
|---|---|---|
| ① 촬영 시점 목록 (BIM으로 고른 10장) | 1. 마커로 사진마다 카메라 위치 구하기 (PnP) | 연결재 84개의 3차원 영역 · 상면 중심 좌표 |
| ② 사진 | 2. 번호 없이 사진 사이 헤드 짝 맞추기 | 결과 파일 `field_chain_summary.json` |
| ③ 헤드 마스크 | 3. 시선 원뿔이 모두 겹치는 곳 = 3차원 영역 | |
| ④ 마커 위치 (측량한 3차원 좌표) | 4. 결과 정리 · 채점 | |

- **짝 맞추기와 영역 계산에는 연결재 번호 · 좌표를 넣지 않는다.** 정답은 결과를 저장한 뒤 채점에만 쓴다.
- **화면 안 완전 투영 규칙**: 가까이 찍으면 진짜 짝이 화면 밖에 있을 때 엉뚱한 헤드가 "유일한 짝"처럼 보인다. 그래서 상대 사진이 그 헤드가 있을 수 있는 범위를 전부 담을 때만 짝으로 인정한다.
- 실행 하나가 끝나면 결과 폴더 4개(카메라 자세 2 × 짝 맞추기 규칙 2)에 `field_chain_summary.json`이 하나씩 생긴다.

## 3. 결과 (시뮬레이션 사진 10장, Run64)

| 카메라 자세 | 짝 맞추기 규칙 | 틀린 짝 | 찾은 연결재 | 상면 중심 오차 mm, 최소 – 최대 (중앙) |
|---|---|---|---|---|
| **마커 PnP (실제 절차)** | 상호 유일 + 화면 안 완전 투영 | **0** | **84/84** | 1.559 – 29.512 (7.770) |
| 정답 자세 (대조군) | 같음 | 0 | 84/84 | 0.033 – 1.267 (0.381) |
| 마커 PnP | 화면 안 완전 투영 없음 | 38 | 44/84 | 1.559 – 16.263 (6.913) |

## 4. 이 저장소

| 경로 | 내용 |
|---|---|
| `examples/run64/<결과 폴더>/field_chain_summary.json` | Run64 실행의 결과 파일 4개 |

## 5. 한계

- 결과는 BIM 모델을 렌더링한 시뮬레이션 사진으로 확인한 값이다. 현장 정확도가 아니다.
- 실제 사진은 헤드 마스크(SAM3 분할)와 측량 마커 좌표를 같은 형식으로 넣도록 설계했지만, 아직 실제 사진으로 돌려 보지 않았다.
